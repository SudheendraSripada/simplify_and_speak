# 📱 Downloadable Mobile App APKs

This folder holds the compiled Android Application Package (`.apk`) files for **Simplify & Speak**.

### 🚀 Direct Download
- **Latest Build**: [`SimplifySpeak-Assistant.apk`](./SimplifySpeak-Assistant.apk)
- Or download the artifact directly from the **Actions** tab on GitHub under the latest workflow run.

### ⚙️ How to Install on Android:
1. Download `SimplifySpeak-Assistant.apk` onto your phone.
2. Tap the downloaded file and choose **Install** (Enable *"Install from Unknown Sources"* if prompted).
3. Open **Simplify & Speak Assistant**:
   - Tap **"Set as Default Assistant"** -> Select *Simplify & Speak* as your Digital Assistant.
   - Tap **"Enable Accessibility Service"** -> Enable the *Simplify & Speak* overlay.
4. **Usage**:
   - **Long-Press Power Button / Home Button**: Extracts and reads the entire screen aloud in simple English.
   - **Highlight Any Text**: A floating `🔊 Simplify & Speak` pill appears automatically on screen.
